# Expense-Tracker

A Python-based application that helps users track their daily expenses and manage their budget effectively.

## Features
- Add new expenses with details.
- View total spending.
- Clear and reset expense records.

## How to Run
1. Ensure you have Python installed on your system.
2. Download or clone this repository.
3. Open your terminal in the project folder.
4. Run the application using the following command:
   ```bash
   python expense_tracker.py
